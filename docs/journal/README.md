# Agent work journal

Chronological continuity log for `general-simulator`. Read the newest month's top entry before
continuing prior work.

Entries live in `YYYY-MM.md`, newest first. Each entry records what was asked, what was found,
what changed, verification, and what remains. Include an entry with non-trivial changes.
Obtain its timestamp with `date '+%Y-%m-%d %H:%M'`; do not trust an ambient date.

Do not rewrite history. If work is reverted or corrected, add a new entry that links to the
earlier one. Use `docs/architecture.md` for lasting design rationale and `docs/gotchas/` for a
reproducible trap.
